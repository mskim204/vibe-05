# 🗳️ 간식 투표앱 (구글 Apps Script 웹앱)

## 시트 준비
스프레드시트에 탭 두 개를 만들어요.

| 탭 | 1행 (제목) | 2행부터 |
|---|---|---|
| `코드` | 코드 | 투표 코드(숫자 4자리) |
| `투표` | 시각 \| 코드 \| 고른 것 | 앱이 자동으로 채워요 |

> `0123`처럼 0으로 시작하는 코드가 있으면 코드 탭의 A열을 **서식 → 숫자 → 일반 텍스트**로 바꾼 뒤 입력하세요.

## 올리기
1. 스프레드시트에서 **확장 프로그램 → Apps Script**
2. `Code.gs`에 [code.gs](code.gs) 내용을 붙여넣기
3. **+ → HTML** 로 `index` 파일을 만들고 [index.html](index.html) 내용을 붙여넣기
4. **배포 → 새 배포 → 웹 앱**, 실행 사용자: 나, 액세스 권한: 모든 사용자 → 배포

## 사용
- 투표 화면: 웹앱 주소 그대로
- 결과 화면: 주소 끝에 `?page=result`

## 동작
- 코드 탭에 없는 코드 → "없는 코드예요"
- 투표 탭에 이미 있는 코드 → "이미 투표했어요"
- 처음 쓰는 코드일 때만 투표 탭에 `시각, 코드, 고른 것`을 저장
- 코드 목록은 서버(code.gs)에서만 확인하고 화면으로는 절대 보내지 않아요
